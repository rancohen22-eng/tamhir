# מערכת עריכת דוחות כספיים · ארקיע · מחלקת חשבות

מערכת רב-משתמשית מבוססת שרת לעריכת דוחות כספיים. שלב 1 מממש את **מודול הליבה** —
עריכת הדוח הכספי — עם תשתית משתמשים, הרשאות, לוג שינויים, וניהול גרסאות.

## יכולות (שלב 1)

לאורך **כל** מסך מוצג ההקשר: **חברה · תקופת דוח · גרסה**.

1. **קליטת מאזן בוחן מאקסל** — העלאת קובץ `.xlsx`, תצוגה מקדימה, מיפוי עמודות
   (מספר חשבון, שם, סעיף מאזן בוחן, כותרות, יתרה שוטפת/קודמת), וייבוא לגרסה.
2. **אינדקס המרה** — מיפוי סעיף מאזן בוחן ← שורת דוח כספי, לכל חברה. כולל זריעה
   אוטומטית של הסעיפים מתוך מאזן הבוחן.
3. **גליון פקודות נוספות** — CRUD מלא (מספר פקודה, כרטיס, סעיף, מהות, סכום).
4. **גליון פקודות מיון** — העברת סכומים בין סעיפים (מסעיף/לסעיף).
5. **דוחות וביאורים** — חישוב אוטומטי (מאזן בוחן + פקודות נוספות + מיונים, ממופה
   דרך האינדקס), עם **תחקור עד רמת החשבון**, והצגת סעיפים לא ממופים.
6. **ייצוא Word** — הפקת `.docx` של הדוחות הראשיים מהנתונים המחושבים.

בנוסף: **ניהול גרסאות** (snapshot / "שמור כגרסה"), **מספר משתמשים במקביל**
(optimistic locking), **לוג שינויים** מלא, ו**ניהול משתמשים והרשאות** (צפייה/עריכה
לכל חברה).

## הרצה מקומית (פיתוח — SQLite)

```bash
cd financial-reports
cp .env.example .env          # NODE_ENV=development
npm install
npm run migrate
npm run seed                  # יוצר משתמש admin / Arkia2026! + חברות + תקופה
npm start                     # http://localhost:3000
```

בדיקת עשן מקצה לקצה: `node server/smoke-test.js`

## פרודקשן — Oracle Autonomous Database (OCI)

1. הורידו את ה-wallet מ-OCI והצביעו עליו עם `TNS_ADMIN`.
2. ב-`.env`: `NODE_ENV=production`, `ORACLE_USER`, `ORACLE_PASSWORD`,
   `ORACLE_CONNECT_STRING` (שם TNS מתוך ה-wallet), `SESSION_SECRET` חזק.
3. `npm run migrate && npm run seed && npm start`.

הלוגיקה זהה בשתי הסביבות (Knex). node-oracledb רץ ב-Thin mode ללא Instant Client.

## ארכיטקטורה

- **בקאנד**: Node.js + Express, Knex (SQLite בפיתוח / Oracle בפרודקשן).
- **פרונט**: vanilla JS + HTML RTL, ללא שלב build, מוגש ע"י Express.
- **אימות**: cookie-session חתום; סיסמאות ב-bcrypt.
- מבנה: `server/` (routes, services, middleware, db) ו-`client/`.

## המשך (שלבים הבאים)

מודול רכוש קבוע (פחת), מודול IFRS 16, מודול הלוואות, וניירות עבודה — ייבנו על אותה
תשתית ויזינו פקודות נוספות ובדיקות התאמה למודול הליבה.
