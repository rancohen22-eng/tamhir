# מרכז פניות LinkedIn

מערכת שמרכזת את הפניות שמגיעות אליך ב-LinkedIn, ממיינת אותן לפי נושא, מכינה מענה ראשוני
ודוחפת אליך את מה שממתין, כל פנייה עם פתרון מוצע.

## איך זה עובד
ל-LinkedIn אין API להודעות של חשבון פרטי, ולכן המערכת קוראת את **מיילי ההתראה** ש-LinkedIn שולח
ל-Gmail (בקשות חיבור, הודעות, InMail).

משימה מתוזמנת של Claude ("LinkedIn inbox triage") רצה 3 פעמים ביום בימים א׳–ה׳ (08:55, 12:55 ו-17:55 שעון ישראל).
היא מופעלת בתוך שיחת ה-Claude Code שבה המערכת נבנתה, כי לשיחה הזו יש גישה ל-Gmail ולדשבורד.
אל תמחק את השיחה הזו. מחיקה שלה עוצרת את הריצות.
בכל ריצה היא:
1. מחפשת ב-Gmail מיילי LinkedIn חדשים שעוד לא טופלו.
2. מסווגת כל פנייה: לקוחות והזדמנויות / שיתופי פעולה / גיוס / שיווק אליך / לא רלוונטי.
3. כותבת תקציר, הצעה לפעולה וטיוטת תשובה בשפת הפונה.
4. מתייגת את המייל ב-Gmail (`LinkedIn/טופל` + תווית לפי נושא) כדי שלא יעובד פעמיים.
5. מעדכנת את הדשבורד.
6. שולחת התראה לטלפון על פניות דחופות, ובריצת הבוקר גם מייל סיכום עם כל הממתינות.

שליחה אוטומטית בתוך LinkedIn לא אפשרית. אתה מעתיק את הטיוטה מהדשבורד ומדביק בשיחה.

## הדשבורד
https://claude.ai/artifact/9mZdLxohJWud9K5PTjM8NK (פרטי, רק לך)

כל פנייה מופיעה ככרטיס עם תקציר, הצעה, טיוטה וכפתור **העתק**, וקישור **פתח ב-LinkedIn**.
"סמן כטופל" או "דחה" מוציאים את הפנייה מרשימת הממתינות וממייל הסיכום הבא.

## הכנה חד-פעמית ב-LinkedIn
Settings → Communications → Email → לוודא שמיילים על **Messages**, **InMail** ו-**Invitations**
פעילים, נשלחים ל-Gmail שלך, ובתדירות **Individual** (ולא תקציר שבועי).
